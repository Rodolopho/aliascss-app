CSS-native styling for humans and AI

If you know CSS, you know AliasCSS.

A deterministic CSS language that turns familiar CSS properties and values into predictable, readable class names.

Try the Compiler Read Documentation
CSS 
transform: rotateY(-90deg)
           translateZ(70px);

box-shadow: 0px -2px 8px
            #00000055;
→
AliasCSS 
transform-rotateY--90deg
__translateZ-70px

box-shadow-0px--2px
-8px-00000055
THE IDEA

CSS without the translation layer.

AliasCSS keeps the relationship between the class and the CSS visible.

01

CSS properties and values map to recognizable AliasCSS class names.

02

Readable

03

AI-friendly

An AI that understands CSS already understands the underlying language.

THE GRAMMAR

Complex CSS stays readable.

AliasCSS adds a small set of predictable grammar rules while keeping the underlying CSS concepts familiar.

NEGATIVE VALUE
transform-rotateY--90deg
CSS VARIABLE
color--fg-color
MULTIPLE FUNCTIONS
transform-rotateY-90deg__translateZ-70px
ATTRIBUTE SELECTOR
[data-state=open]-display-none
